# WS2 — Graphs From Scripts (every claim gets a saved figure)

Back to [deeper-exploration-roadmap.md](./deeper-exploration-roadmap.md). Phase 1.
Cross-cutting: every other workstream emits its figures through this layer.

## Hard requirement (from the user)

"Numbers can be useless if the graph shows something is wrong." EVERY claim must have a
SAVED FIGURE (PNG) the user can open and inspect, produced BY the scripts, written to a
figures directory — NOT inline / notebook-only. A workstream is not done until its
figures exist on disk.

Today only `hubble_diagram_nbody.py` emits a PNG (`fig.savefig(out_path, dpi=150,
bbox_inches="tight")` to `--output-dir`, default `./results`) and `convergence_check.py`
has a `--png` flag. The sweep tools emit CSVs but no figures. This workstream makes
figure output a first-class, uniform part of the sweep + diagnostic scripts.

## Proposed location + naming

- Directory: `results/figures/<workstream>/` (generated artifact, git-ignored with
  `results/*.csv`; regenerated by scripts; never hand-edited).
- Filenames: descriptive + parameterized, e.g.
  `ms_chi2_heatmap_vs_pantheon_geom-cube26_init-uniform.png`,
  `growth_map_geom-shell32.png`, `eds_overlay_M0.png`,
  `mu_z_panel_M855_S37.8.png`, `runaway_boundary_cube26.png`.
- A shared plotting helper module (e.g. `cosmo/plots.py`) so every script saves with
  the same style (dpi=150, bbox_inches="tight", consistent axis labels, a footer
  stamping the config + git rev for traceability). Paper-final figures are still
  promoted into `docs/fig*.png` by hand (as today).
- A `--plots-only <csv>` mode (WS1) regenerates all figures from a saved results CSV
  without re-running sims.

## Definition of done per workstream

A workstream's claim is only "pinned" when its figure(s) from the table above exist in
`results/figures/<workstream>/` and have been eyeballed for anything the number hides
(e.g. a good chi2 sitting on a runaway edge, a degenerate flat band, a mask-shaped
anisotropy).

## Files this workstream touches

- NEW: `cosmo/plots.py` (shared style + save helper + the heatmap/map plotters).
